# Library Management System

## 1. Project Title

Library Management System

## 2. Overview of the Project

The Library Management System is a Python-based console application used to
manage books in a library.

The system allows the user to:
- Add books
- View all books
- Remove books
- Find a book using its ID
- Issue books
- Return books
- Exit the application

The project is divided into multiple Python files using modules. The main
file controls the program, while separate modules handle book management
and book issue/return operations.

## 3. Features

- Add one or more books to the library.
- Store book ID, book name, author name, book status, and book price.
- View all books stored in the library.
- Find a book using its book ID.
- Remove a book using its book ID.
- Issue an available book.
- Return a borrowed book.
- Validate book status as `available` or `borrowed`.
- Handle invalid numeric input using exception handling.
- Menu-driven console interface.
- Modular Python program using separate files.

## 4. Technologies / Tools Used

- Programming Language: Python
- Interface: Command Line / Console
- Python Modules:
  - `main.py`
  - `semi_file.py`
  - `book_issue.py`

The project uses Python functions, lists, loops, conditional statements,
exception handling, and modules.
